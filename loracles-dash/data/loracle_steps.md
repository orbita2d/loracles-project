**What this is.** The LoRAcle (ceselder/loracle-ptrl-v9, buggy-V tokens, the six "Ask the LoRAcle" preset questions × 4 samples at T = 0.5) run on (a) every saved v2 checkpoint and (b) each cached weight update Δ_K = θ[S+K] − θ[S] (K = 1, 5, 10, 25 steps), turned into a LoRA two ways: **tangent** dW = s(dB·A + B·dA), the first-order weight change the update makes, and **raw** dW = s·dB·dA, the update file loaded as if it were an adapter. Each update is rescaled per module to the final adapter's norm, but the LoRAcle normalises every direction token, so scale cannot change what it reads.
